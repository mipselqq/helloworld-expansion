# Artemis II · Hello, World

Воспроизводимый конвейер для обоев 21:9 из снимка NASA `art002e000192`. Цветовая модель обучается на геометрически совмещённых участках 8K-видео melodysheep. Снимок и атмосфера остаются фотографическими. Звёзды за границами исходного кадра рассчитываются по Hipparcos и траектории Orion.

## Запуск

### Графический редактор

После установки зависимостей запустите `./run-editor.sh`. Окно открывается на весь экран; `Esc` или `F11` переключает полноэкранный режим. Разрешение сохранения определяется по текущему экрану и может быть изменено вручную. Флажки управляют цветокоррекцией, звёздами в расширении, фактурой неба, зерном видео, удалением полос и ослаблением широкого солнечного свечения. По умолчанию выбрана обычная резкость (`Conventional`). Сохранение выполняется в PNG или TIFF с глубиной 16 бит и профилем изображения.

Колёсико приближает и отдаляет относительно курсора, перетаскивание мышью перемещает изображение, кнопка `Reset zoom` возвращает общий вид. При увеличении обрабатывается видимый участок с запасом для фильтров. Пока он рассчитывается, показывается быстрое приблизительное изображение. Устаревшие запросы превью отменяются; сохранение фиксирует выбранные настройки и не блокирует работу с окном.

Для отзывчивости общий вид создаётся с уменьшенной копии, а экранное зерно и фактура фона на нём могут быть не видны. На увеличенном участке шум синтезируется заново, поэтому рисунок конкретных зёрен в превью не обязан побайтно совпадать с сохранённым изображением; оригинальные детали планеты и положения звёзд сохраняются. Экспорт каждый раз обрабатывается на полном разрешении. Исходные файлы и результаты кэшируются в каталогах проекта; первый запуск и первое переключение некоторых настроек занимают больше времени.

В репозитории уже находятся JPEG и RAW NASA, выбранный фрагмент видео, Hipparcos, береговая линия, нужные ядра SPICE и компактные исходные калибровки. После клонирования их целостность можно проверить командой `sha256sum -c SOURCE_SHA256SUMS`; для воспроизведения используйте `--offline`. Расчётный кэш, виртуальное окружение и готовые обои не включены в Git и создаются локально. Размещение и повторное распространение видеоматериала зависит от прав правообладателя.

Для запуска нужны Python 3.12, Tk и FFmpeg/FFprobe с декодером AV1. Python-зависимости закреплены в `requirements.txt`; для их первой установки нужен доступ к пакетному индексу. yt-dlp, Firefox и Deno нужны только для повторной загрузки фрагмента YouTube. Конвейер вызывает `/usr/bin/yt-dlp` с `--cookies-from-browser firefox`; сами куки в проект не записываются.

```sh
uv venv --python 3.12 .venv
source .venv/bin/activate
uv pip sync requirements.txt
export OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=4
python -m artemis --offline
python -m pytest -q
```

Вместо uv можно установить `requirements.txt` через pip в окружение Python 3.12. Запускайте команды из корня проекта. На исходном компьютере расчёт выполнялся на CPU. Свободное место для исходников, кэша и всех результатов составляет около 1,5–2 ГБ.

Для повторного рендера без сети и для отдельных этапов

```sh
python -m artemis --stage acquire
python -m artemis --offline --stage calibrate
python -m artemis --offline
python -m artemis --offline --refresh-video
```

`--stage acquire` загружает JPEG, короткий 8K-фрагмент, каталог и ядра SPICE. В текущем проекте скачанный RAW уже находится в `cache/source/art002e000192.NEF`. Если NASA очистит временное хранилище RAW, откройте [запись JSC](https://esrs.jsc.nasa.gov/SearchPhotos/photo.pl?mission=ART002&roll=E&frame=192), выберите Download Options → Raw file from camera → Request, дождитесь ссылки архива и повторите этап загрузки. Рендер может использовать опубликованный JPEG, пока RAW готовится. Архивные исходники и производные кэши можно хранить отдельно и использовать с `--offline`.

## Где вносить правки

| Что изменить | Файл |
|---|---|
| Время видео, формат, число соседних кадров, зерно, холст | `config.toml` |
| Загрузка, метаданные, контрольные суммы | `artemis/acquire.py` |
| Выбор кадра и геометрическая регистрация | `artemis/video.py` |
| Детектор лимба и компоновка | `artemis/geometry.py` |
| Ослабление широкого солнечного свечения и шума | `artemis/sun_glow.py`, секция `[sun_glow]` в `config.toml` |
| Камера, SPICE, модель объектива, абсолютная привязка | `artemis/astrometry.py` |
| Координаты и движение звёзд Hipparcos | `artemis/catalog.py` |
| Детектор точечных источников и апертурная фотометрия | `artemis/photometry.py` |
| Порог обнаружения, цвет, PSF и размещение звёзд | `artemis/sky_render.py` |
| Обработка NEF и восстановление светов | `artemis/raw.py` |
| Подбор цветовой модели и метрики | `artemis/color.py` |
| Поиск и удаление оптических полос | `artemis/flare.py`, секция `[flare]` в `config.toml` |
| Коррекция деталей по масштабам и проверка на сиянии | `artemis/sharpness.py`, секция `[sharpness]` в `config.toml` |
| Экранное зерно видео, измерение и наложение | `artemis/video_grain.py`, секция `[video_grain]` в `config.toml` |
| Фон, продолжение поля и образцы зерна | `artemis/background.py`, `artemis/texture.py` |
| Композит и экспорт | `artemis/compose.py` |
| WCS, отчёт и диагностика | `artemis/validation.py`, `artemis/report.py` |

Кэш `cache/work/reference.npy` и `cache/work/registration.json` хранит выбранный кадр и оценки соседних кадров. После изменений алгоритма регистрации, целевой отметки или окна выбора используйте `--refresh-video`. При изменении границ скачиваемого фрагмента или формата переместите прежний `cache/source/melodysheep_clip.mp4` и скачайте новый. Если меняете проявление RAW, переместите `cache/work/raw_active.npy` перед запуском. Аргумент `--config` принимает путь к другому TOML. Пути к кэшу и результатам считаются от его каталога.

## Результаты и проверка

В `output/` находятся два полноразмерных 16-битных мастера, обои 3440 × 1440, сопоставление цвета, диагностика стыков и астрометрии, сравнение фактуры `sky_texture_comparison.png`, диагностика оптических полос `flare_analysis.png`, сравнение экранного зерна `video_grain_comparison.png`, сравнение деталей у сияния `sharpness_comparison.png`, FITS WCS, списки подтверждённых и добавленных Hipparcos-источников, `measurements.json` и `report.md`. PNG и TIFF мастера содержат одинаковые пиксели. Для просмотра исходной кромки, деталей и стыков на 100% и 200% используйте `cache/work/inspection/`.

Коррекция полос включается через `[flare].enabled`. Направляющие `flare.ridges.guide` заданы в пикселях исходного кадра. Детектор уточняет центр и ширину каждой полосы по соседним профилям и сохраняет измерения в JSON. Параметры `halo_along_px` и `halo_half_width_px` задают область второго прохода для широкого остаточного ореола. Поправка оценивается по фону по обе стороны дуги.

Отдельный переключатель `Reduce sunward sky glow` ослабляет яркий широкий фон и его шум, сохраняя диск, узкую атмосферную кромку и точки звёзд. Это художественная коррекция: [NASA описывает зодиакальный свет в этой области](https://science.nasa.gov/earth/earth-observatory/a-moonlit-earth-as-seen-from-artemis-ii/), поэтому удалённое свечение нельзя целиком считать дефектом объектива. Силу и защиту кромки можно настроить в `[sun_glow]`; отключение возвращает исходный широкий фон.

Экранное зерно измеряется по двум группам кадров после компенсации движения фотографии. Кэш измерения хранится в `cache/work/video_grain_model.json`. Параметр `[video_grain].strength` масштабирует измеренную интенсивность в финальном рендере.

Координаты в CSV и JSON нумеруются от нуля. FITS использует нумерацию FITS. Расширенные звёзды проверяются на соответствие принятой виртуальной проекции. Их положения за пределами сенсора остаются модельными. Числа ΔE считаются на отложенных пикселях общей области кадра NASA и видео. Допуски проверяются тестами в `tests/`.
